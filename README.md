## Описание проекта

В этом проекте проводится тестирование API учебного сервиса Яндекс Самокат.  
Цель — проверить корректность работы основных ручек API: создание курьера, авторизация курьера, создание заказа и получение списка заказов.

Документация к API:  
[https://qa-scooter.praktikum-services.ru/docs/](https://qa-scooter.praktikum-services.ru/docs/)

Базовый URL сервиса:  
`https://qa-scooter.praktikum-services.ru/api/v1`

---

## Функционал, покрытый тестами

### Создание курьера

- Курьера можно создать;
- Нельзя создать двух одинаковых курьеров;
- Проверка обязательных полей;
- Проверка корректных кодов ответов;
- Успешное создание возвращает `{"ok": true}`;
- Ошибка при отсутствии обязательных полей;
- Ошибка при попытке создать дубликат логина.

### Логин курьера

- Успешная авторизация курьера;
- Проверка обязательных полей при авторизации;
- Ошибка при неверном логине или пароле;
- Ошибка при авторизации несуществующего пользователя;
- Успешный логин возвращает `id`.

### Создание заказа

- Можно указать один цвет (`BLACK` или `GREY`);
- Можно указать оба цвета;
- Можно не указывать цвет вовсе;
- В ответе присутствует `track`.

### Список заказов

- Возвращается список заказов в теле ответа.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone <URL_твоего_репозитория>
cd Sprint_7
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустить тесты

```bash
pytest -v
```

или с подробным выводом:

```bash
pytest -s -v
```

---

## Генерация отчёта Allure

### 1. Запустить тесты с генерацией отчёта

```bash
pytest --alluredir=allure-results
```

### 2. Сформировать и открыть отчёт

```bash
allure serve allure-results
```
